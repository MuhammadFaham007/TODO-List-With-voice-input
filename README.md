# 🎙️ TODO List with Voice Input

A simple and interactive **To-Do List Web Application** that lets users manage their daily tasks using text input and voice recognition. This project combines task management with speech-to-text functionality to make adding tasks faster and more convenient.

## ✨ Features

- **Voice Input:** Add tasks by speaking through your microphone.
- **Manual Input:** Enter tasks using the keyboard.
- **Task Management:** Organize your daily tasks in one place.
- **Delete Tasks:** Remove tasks you no longer need.
- **Mark as Completed:** Keep track of completed tasks.
- **Responsive Design:** Use the application on different screen sizes.
- **Interactive UI:** A simple interface for managing everyday tasks.

## 🛠️ Technologies Used

- **HTML5** — Application structure
- **CSS3** — Styling and responsive layout
- **JavaScript (Vanilla JS)** — Application logic and interactivity
- **Web Speech API** — Voice recognition and speech-to-text functionality

## 🚀 Getting Started

Follow these steps to run the project on your computer.

### 1. Clone the Repository

```bash
git clone https://github.com/MuhammadFaham007/TODO-List-With-voice-input.git
```

### 2. Open the Project Folder

```bash
cd TODO-List-With-voice-input
```

### 3. Run the Application

Open the `index.html` file in your browser.

Alternatively, use the **Live Server** extension in Visual Studio Code for a better development experience.

## 🎤 How to Use Voice Input

1. Open the application in a supported browser.
2. Allow microphone access when prompted.
3. Click the voice input or microphone button.
4. Speak the task you want to add.
5. Review the recognized text and add the task to your list.
6. Mark tasks as completed or delete them when necessary.

**Note:** Voice recognition depends on browser support and microphone permissions. Google Chrome generally provides good support for the Web Speech API.
